---
title: bmux CLI
description: Convert and compress images, and tag audio for Spotify Local Files, locally from the command line.
---

bmux converts and compresses images, and tags local audio files for Spotify's Local Files
feature, without uploading them anywhere. The [browser app](https://bmux.bluejutzu.dev) does the
work in your own tab; the CLI does the same jobs from a script, with no server involved for
either — audio tagging's only exception is the optional, opt-in MusicBrainz lookup in
[`batch`](/bmux/commands/batch).

<Note>
  The CLI uses [sharp](https://sharp.pixelplumbing.com/), so unlike the browser it can write every
  supported format and can keep EXIF metadata when you ask it to.
</Note>

## Quickstart

<Steps>
  <Step title="Install">
    ```bash
    npm install -g @bluejutzu/bmux
    ```

    See [Installation](/bmux/installation) for pnpm, yarn, and building from source.
  </Step>

  <Step title="Convert something">
    ```bash
    bmux convert photo.jpg --to webp --quality 80
    ```
  </Step>

  <Step title="Check what you got">
    ```bash
    bmux inspect photo.webp
    ```
  </Step>
</Steps>

## Audio

Tag local mp3/flac/m4a files so Spotify's **Local Files** feature shows their title, artist,
album, and cover art correctly — the same feature lives in the [browser app](https://bmux.bluejutzu.dev)
as the **Spotify Tracks** tab.

<CardGroup cols={3}>
  <Card title="tag" icon="tag" href="/bmux/commands/tag">
    Write specific fields — title, artist, album, track, year, cover art — on one file.
  </Card>

  <Card title="batch" icon="layer-group" href="/bmux/commands/batch">
    Apply the same artist/album/year/cover to every file in a directory at once.
  </Card>

  <Card title="cover" icon="image" href="/bmux/commands/cover">
    Extract or replace embedded cover art on its own.
  </Card>
</CardGroup>

## Things that hold true everywhere

- **Originals are never overwritten.** Colliding output names get a numeric suffix unless you
  choose otherwise with `--collision`.
- **Metadata is stripped by default.** EXIF/XMP is removed unless you pass `--preserve-metadata`.
  Photos are still auto-rotated upright first.
- **A failed file doesn't stop the rest.** The batch finishes, the failures are listed, and the
  exit code is non-zero.
- **Nothing is uploaded.** There is no server and no account. `--dry-run` will show you exactly
  what would be written before anything is.

## Colour output

Colour is used for status only — green for a saving, amber for a file that grew, red for a failure.
It turns itself off when output isn't a terminal, and it honours
[`NO_COLOR`](https://no-color.org):

```bash
NO_COLOR=1 bmux convert photo.jpg --to webp
```
